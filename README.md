Программная инженерия — 2026

Публичные материалы учебного курса «Программная инженерия», читаемого в 2026 году в Финансовом университете при Правительстве Российской Федерации.

Материалы курса

В репозитории публикуются актуальные материалы, предназначенные для студентов:

презентации лекций; конспекты лекций для самостоятельного изучения и подготовки к экзамену; задания и материалы семинарских занятий.

Материалы курса обновляются по мере прохождения соответствующих тем.

Структура репозитория lessons/ — материалы лекций lecture-notes/ — конспекты лекций seminars/ — задания и материалы семинарских занятий

Репозиторий содержит только опубликованные версии учебных материалов. Исходные и рабочие материалы разработки курса хранятся отдельно и не публикуются.
